# content/lessons — Lesson Content

This directory holds structured lesson content for the Learn module.

## Status

🚧 **Phase 2** — Lesson content will be authored here when the Learn module is built. The content schema will be defined in Phase 2 and documented here.

## Planned Lessons

1. **X Gate** — Pauli-X (bit flip)
2. **Y Gate** — Pauli-Y
3. **Z Gate** — Pauli-Z (phase flip)
4. **H Gate** — Hadamard (superposition)
5. **Phase Gate** — General phase rotation
6. **CNOT Gate** — Controlled-NOT (entanglement)
7. **Toffoli Gate** — Double-controlled NOT

## Content Schema (TBD in Phase 2)

Each lesson will be a directory containing:
- `meta.json` — Title, order, prerequisites, gate covered
- `content.mdx` — Explanation with KaTeX math and circuit diagrams
- `quiz.json` — Assessment questions
- `practice.json` — Mini-challenge exercises

See `IMPLEMENTATION_PLAN.md` Phase 2 for details.
